Đoạn mở đầu giới thiệu về chủ đề bài viết. Nêu rõ vấn đề bạn muốn giải quyết hoặc thông điệp bạn muốn truyền tải đến người đọc.

"Một câu trích dẫn hoặc tóm tắt nổi bật để gây ấn tượng với người đọc."

1. Tiêu đề mục chính thứ nhất

Nội dung giải thích chi tiết cho mục 1. Bạn có thể chèn code inline như console.log() hoặc các liên kết. 

// Ví dụ mã nguồn JavaScript
function helloWorld() {
    console.log("Xin chào từ Lê Anh Minh Blog!");
}
helloWorld();

2. Tiêu đề mục chính thứ hai

Nội dung giải thích tiếp theo. Bạn có thể sử dụng danh sách gạch đầu dòng:

  • Điểm quan trọng thứ nhất cần lưu ý.
  • Điểm quan trọng thứ hai.
  • Điểm quan trọng thứ ba.

3. Tổng kết

Tóm lược các ý chính và đưa ra lời khuyên hoặc hướng phát triển tiếp theo cho độc giả.
