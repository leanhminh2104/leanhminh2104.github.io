Laravel Tips — Những trick hay mình hay dùng 💡

Lê Anh Minh 27 tháng 9, 2026 5 phút đọc
Laravel PHP Backend

Laravel là một framework rất tuyệt vời với hệ sinh thái phong phú và syntax cực kỳ tao nhã (expressive). Tuy nhiên, có rất nhiều helper và tính năng ẩn mà ít người chú ý tới, nhưng lại giúp code của bạn ngắn gọn, dễ đọc và tối ưu hiệu năng hơn rất nhiều.

"Viết code không chỉ là để máy tính hiểu, mà quan trọng hơn là để đồng nghiệp và chính bạn 6 tháng sau đọc lại vẫn thấy dễ chịu."

1. Dùng cursor() thay vì chunk() khi duyệt lượng dữ liệu lớn

Khi cần duyệt qua hàng ngàn hay hàng chục ngàn record trong database, nhiều dev thường dùng chunk(). Nhưng chunk() thực chất chạy nhiều câu query phân trang với LIMIT và OFFSET. Với bảng lớn, query offset càng về sau càng chậm.

Thay vào đó, bạn có thể dùng cursor(). Phương thức này tận dụng PHP Generators (hàm yield), chỉ chạy 1 câu query duy nhất và nạp từng model vào RAM tại một thời điểm, giữ bộ nhớ luôn ở mức tối thiểu: 

// Tiết kiệm RAM vượt trội với cursor()
use App\Models\Order;

foreach (Order::where('status', 'pending')->cursor() as $order) {
    $order->processPayment();
}

2. Tận dụng when() và unless() trong Query Builder

Thay vì viết các khối if...else rời rạc để ghép query tìm kiếm hay lọc dữ liệu, bạn hãy sử dụng method when(): 

$users = User::query()
    ->when($request->filled('search'), function ($query) use ($request) {
        $query->where('name', 'like', "%{$request->search}%");
    })
    ->when($request->role, function ($query, $role) {
        $query->where('role', $role);
    })
    ->get();

Cách viết này giúp chuỗi query liền mạch, dễ đọc và rất dễ bảo trì.

3. Tạo Custom Eloquent Collection

Nếu bạn thường xuyên phải thực hiện các phép tính toán nghiệp vụ trên tập hợp model (như tính tổng doanh thu sau thuế, phân loại đơn hàng), đừng nhồi nhét logic đó vào Controller. Hãy tạo một Custom Collection: 

// Trong Model Order.php
public function newCollection(array $models = [])
{
    return new OrderCollection($models);
}

// Trong app/Collections/OrderCollection.php
class OrderCollection extends \Illuminate\Database\Eloquent\Collection
{
    public function totalRevenue(): float
    {
        return $this->sum(fn ($order) => $order->subtotal - $order->discount);
    }
}

// Gọi cực kỳ thanh lịch ở bất cứ đâu:
$orders = Order::whereDate('created_at', today())->get();
echo $orders->totalRevenue();

4. Dùng helper tap() để giữ method chaining liền mạch

Helper tap() cho phép bạn thực hiện hành động trên một đối tượng và sau đó trả về chính đối tượng đó: 

// Cập nhật model và trả về model đã update trong 1 dòng:
return tap($user)->update([
    'last_login_at' => now(),
]);

5. Đo đạc tốc độ thực thi với Benchmark::measure()

Từ Laravel 9.32+, Laravel tích hợp sẵn class Benchmark cực kỳ tiện dụng để test hiệu năng mà không cần cài thêm extension phức tạp: 

use Illuminate\Support\Benchmark;

Benchmark::dd([
    'Method A' => fn () => User::with('posts')->get(),
    'Method B' => fn () => User::all()->load('posts'),
]);
